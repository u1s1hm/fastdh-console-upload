# FastDH 团队上传技能

[发行版与安装包](https://github.com/u1s1hm/fastdh-console-upload/releases) · [更新日志](CHANGELOG.md) · [维护约定](MAINTAINING.md) · [技能入口](SKILL.md)

与 fastdh-live-package v0.3.1 配套：生成技能负责内容包；本技能负责将包应用到 FastDH 控制台。版本 0.2.0。

本版优先使用宿主内置浏览器，先检查文件上传能力，再通过已验证的批量入口准备、提交和回读配置。正常路径不再逐项点击创建编排；局部更新保留其它字段，中断后先查已保存结果再续传。原始包默认只读。

## 安装

推荐向 Codex 发送以下请求，用固定版本安装：

```text
请使用 skill-installer 安装 https://github.com/u1s1hm/fastdh-console-upload。
仓库根目录是技能目录，名称 fastdh-console-upload，固定到 v0.2.0。
若已安装，请先检查本地修改，再更新。
```

手动安装请从 [v0.2.0 Release](https://github.com/u1s1hm/fastdh-console-upload/releases/tag/v0.2.0) 下载 `fastdh-console-upload-v0.2.0.zip`，可用同页 `SHA256SUMS.txt` 核验完整性。GitHub 自动生成的 Source code 压缩包也可用，但需将顶层文件夹改名为 `fastdh-console-upload`。

将压缩包解压，把整个 `fastdh-console-upload` 文件夹放进 Codex 的 `$CODEX_HOME/skills`（未设置时为 `~/.codex/skills`）。确保 SKILL.md 直接在该文件夹下。无需复制原作者的工作目录或桌面手册；不含共享账号和卡密。其它支持 SKILL.md 的 Agent 可放其技能目录，仍需该宿主可用的浏览器工具和文件上传能力。

需要 Python 3（本地工具使用标准库，无 pip 依赖）、可读本地文件的 Agent，以及浏览器自动化/文件上传工具。Codex 内置浏览器已在本次案例完成模板上传，无需为此额外安装扩展。其它宿主先检测能力，只有缺少必要能力才引导连接外部浏览器；不会自装 CLI 或修改系统设置。它是由 Agent 执行的自动化技能，不是脱离 Agent 单独运行的一键软件。

## 使用

向 Agent 发送：

```text
使用 $fastdh-console-upload。
请先引导我用自己的卡密登录。
我的配置包目录：<绝对路径>。
原始文件只读；优先使用内置浏览器和已确认的批量配置入口。
本次新建 Agent 和独立 Live 场景，中文名为 <名称>。
请自动填写、上传模板知识、保存并回读，完成后设为 active，不开播。
```

登录入口固定为 https://www.vivalive.ai/fastdh-front/ops/fastdh 。在网页登录表单输入自己的卡密，不需要发在聊天里。登录成功后补充包目录、新建/更新目标、发布状态和媒体登记情况。已有本人登录可复用。

局部更新示例：“更新 Agent ID … / Scenario ID …，只修改 R02 回复规则，其它值保留。”同名对象需选清楚。执行中仅对缺失信息、影响结果的冲突或登录提出问题，常规填表/保存/回读自动完成。

中断恢复示例：“继续上次上传，目标 Agent ID … / Scenario ID …。先回读成功项，再处理未完成项。”提供上次结果摘要或获准保存的包外进度记录即可；不要发送卡密、Cookie 或完整敏感快照。

原视频仍由运营在数字人执行端上传并按映射命名；本技能上传的是 FastDH 配置和模板知识。模板绑定未确认、精确触发不被支持等项会明确停在待核，不假称上线完成。

## 验证范围

2026-11-25 的既有实际上传证明：Codex 内置浏览器可上传模板，场景 JSON 可保存并回读 61 项编排及 2 条规则。这些是案例数量，不是平台上限；没有确认可直接复用的 HTTP API，当次页面未提供 WebMCP。

本版新增离线回归覆盖批量合并、旧 ID/未知字段保留、数组删除范围、目标与版本冲突、非空行/备注范围、零/单/双规则、超时与异步恢复决策、正文回读差异和源文件只读。它们验证工具逻辑，不模拟真实浏览器事件或网络服务；新流程未再次写入生产场景，未做实播。其它宿主和新成员卡密尚未逐一端到端测试。保存回读、规则预览、实播分开报告。

开发检查：`python -m unittest discover -s tests -v`。本包预检不替代逐字段审阅与页面回读。批量工具只读本地输入、向标准输出生成临时载体，使用说明见 [批量准备](references/batch.md)；不会自己登录或调用 FastDH。

## 环境问题如何处理

| 情况 | 技能会采取的方式 |
|---|---|
| 内置浏览器可控制且能上传 | 直接使用，无需扩展 |
| 能控制页面但不能选择本地文件 | 说明缺失的上传能力，优先宿主受支持的文件传递；必要时引导连接外部浏览器并重新核对身份 |
| 没有已验证的接口 | 使用页面 JSON；仅未覆盖的板块用表单 |
| 页面值改变但保存未生效 | 先验证输入事件和保存结果，再继续批量；不会机械重复填表 |
| 平台校验失败、版本冲突或部分成功 | 回读并定位问题，只恢复失败部分；未解决的依赖项明确报告 |

具体浏览器插件和权限由当前宿主工具决定，不把一种浏览器的条件强加给全团队。详见 [能力选择](references/transport.md) 和 [执行恢复](references/workflow.md)。

## 升级与问题反馈

`VERSION`、Git 标签与 Release 对应；固定标签适合团队统一版本，`main` 可能包含未发布改动。升级先看 [更新日志](CHANGELOG.md)，保护本地修改，不覆盖自定义内容。升级技能不自动改已有 FastDH 场景。

配套生成技能：[fastdh-live-package v0.3.1](https://github.com/u1s1hm/fastdh-live-package/tree/v0.3.1)。两个技能独立发布；未来兼容版本须经验证后更新说明，不能只按版本号推断兼容。

反馈请在 [Issues](https://github.com/u1s1hm/fastdh-console-upload/issues) 提供技能版本、宿主/浏览器、失败板块、脱敏的预期与实际结果，并区分保存回读、规则预览和实播。不要提交卡密、Cookie、真实媒体或包含账号资料的后台截图。
